# Travel-360 ✈️

AI-powered enterprise travel concierge platform focused on privacy, governance, ESG visibility, and intelligent ride-sharing workflows.

## Live Demo

Frontend Dashboard:  
https://travel-360.streamlit.app/

Backend API Docs:  
https://travel-360.onrender.com/docs

---

## Core Features

### 🔒 Privacy Protection Layer
- Real-time PII masking
- Passport tokenization
- Loyalty/Member ID sanitization
- Audit-safe processing pipeline

### 🌱 ESG Sustainability Engine
- Flight carbon footprint estimation
- Green travel indicators
- Deterministic ESG scoring
- Sustainability alerts

### 🚖 Smart Ride Pooling
- Detects overlapping airport arrivals
- Suggests shared transportation
- Reduces enterprise travel costs
- Improves sustainability metrics

### 🛡 Governance Workflow
- Policy exception handling
- Manager approval workflows
- Approval justification logging
- Audit logging support
